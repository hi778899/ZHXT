# V17.7.14 数字化库全量模型运行归档

本版本采用方案A：所有正式数字化库记录必须由对应数据产生模型的一次真实运行形成。

## 核心链路

`数据产生模型 → model_runs → 标准模型文件名 → digital_library_records`

正式记录必须保存真实 `run_id`，并保证 `digital_library_records.file_name = model_runs.file_name`。

## 历史记录

历史 `std-*`、`src0622-*`、`auto0622-*` 技术键仅保留在 `legacy_record_id` 中。历史无运行来源记录通过 `system_initialization` 运行物化；后续系统源变化通过 `system_sync` 运行归档。

## 数据库

新增 `026_materialize_all_digital_library_records_as_model_runs.sql`，包括历史物化函数、异常清单和正式记录运行来源约束。
