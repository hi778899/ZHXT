# V17.1.2.1 TypeScript 生产构建修复说明

日期：2026-09-12

本版基于 V17.1.2，仅修复生产 Docker 构建阶段的 TypeScript 严格类型错误，不改变历史数字化库数据映射、四阶段模型、审批模型、智选模型和数据库迁移逻辑。

## 修复内容

`server/src/data-linkage.ts` 中历史数字化库修复函数的 `design` 变量原由 `Map.get()` 推断为 `Record<string, unknown> | undefined`。即使运行逻辑在分支中完成了兜底赋值，TypeScript 严格模式仍无法在后续语句中保证其一定非空，从而导致：

- TS2345：`Record<string, unknown> | undefined` 不能传给 `Record<string, unknown>`；
- TS18048：`design` 可能为 `undefined`。

本版改为显式声明 `design: Record<string, unknown>`，并分别处理缓存命中和数据库加载两条路径，确保两条路径结束后 `design` 一定有值。

## 验证

已对修改后的 `data-linkage.ts` 进行 TypeScript `strict` 模式独立类型检查，修复前出现的 TS2345 / TS18048 均已消除。
