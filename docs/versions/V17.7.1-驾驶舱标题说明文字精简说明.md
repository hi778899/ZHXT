# V17.7.1 驾驶舱标题说明文字精简说明

## 修订内容

驾驶舱继续使用“工作台、快捷入口、我的事项、工作概览、常用服务”的成熟企业工作台结构。

本次不调整功能结构，仅精简区域标题展示：

- “快捷入口”仅显示标题，不再显示用途解释；
- “我的事项”仅显示标题，不再显示待办/已办/办结解释；
- “工作概览”仅显示标题，不再在标题区说明统计数据来源；
- “常用服务”仅显示标题，不再在标题区说明权限匹配逻辑。

数据来源、权限、交互和统计口径仍按 `.ai/rules/18_DASHBOARD_RULES.md` 执行，仅不作为区域标题下的可见说明文字。
