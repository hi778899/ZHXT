# V17.7.4 智选已办/办结统一运行详情

## 修订目标

修复用户从“我的已办”“我的办结”或业务模型关联模型中点击智选模型后页面空白的问题，并统一智选模型查看的数据主键和真实数据来源。

## 核心规则

- 三个入口统一使用同一 `smart_run_id`。
- 智选详情以 `model_runs.id` 为唯一运行主键。
- 后端按 `smart_run_id` 读取智选运行、来源审批运行、原业务运行、智选数字化库和原业务数字化库。
- `todo.content` 和列表快照不再作为智选详情主数据源。
- 智选详情固定为“模型信息、业务内容、审批结果、统计分析、智选判断、关联模型启动明细”六个区域。
- 无后续模型、审批不同意、启动次数为0均正常显示。
- 历史单字段缺失显示 `—/无/未形成`；运行记录不存在显示明确错误信息，不允许白屏。

## 代码变更

- 新增 `GET /api/model-runs/:runId/detail` 智选真实运行详情接口。
- 已办/办结关联智选记录传递 `runId`。
- 新增统一 `SmartRunDetail` 组件，按 `runId` 实时读取详情。
