# V16.1 生产构建修复说明

修复 `server/src/model-builder.ts` 中 TypeScript TS5076：空值合并运算符 `??` 与逻辑或 `||` 未使用括号隔离导致 `pnpm run build:all` 在服务端 TypeScript 编译阶段失败。

原逻辑用于确定业务定义层级。现改为先计算 `parentLevel`，再用明确条件处理无效数字：

```ts
const parentLevel = Number(parent.rows[0]?.level_no ?? 0)
const level = levelMap[levelText] ?? (Number.isFinite(parentLevel) ? parentLevel + 1 : 1)
```

该改动不改变前端构建和数据库结构，不需要新增迁移。
