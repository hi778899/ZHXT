# V17.7.21 全系统模型数字化配置完整性

本版将 V17.7.20 的“请假类型标准模型/模型时限模型个别补齐”升级为全系统机制。

- 扫描全部已发布、可运行模型；
- 每个模型必须具备当前19位模型数字化编码和0622模型数字化配置；
- 系统基础模型缺少人工分类时统一使用正式“数字化管理”业务分类，考勤模型使用“考勤管理”；
- 其他无法唯一判断的模型进入 `model_digital_config_completeness_issues`，不猜测；
- 所有已使用业务分类必须具备基础行政审批分管和模型时限覆盖；
- 除审批模型、智选模型自身外，所有已发布可运行模型统一强制进入审批→智选模型簇；
- 模型发布时立即形成模型数字化配置，不再等第一次运行后报错；
- 所有补齐仍通过对应数据产生模型真实运行写入数字化库，不直接生成 `run_id=NULL` 正式数据。
