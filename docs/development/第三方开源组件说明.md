# 第三方开源组件说明

## React Flow / @xyflow/react

- 用途：**单个模型内部运行结构**的节点画布、自由连线、缩放平移、MiniMap、Controls、自定义节点与连接校验。跨模型关系（例如“请休假模型归档 → 审批模型”）不画成节点，统一在第 4 阶段“配置”中维护。
- 版本范围：`@xyflow/react ^12.11.6`。
- 上游项目：https://github.com/xyflow/xyflow
- 官方文档：https://reactflow.dev/
- npm：https://www.npmjs.com/package/@xyflow/react
- 许可证：MIT（发布/部署时应继续遵守上游许可证要求）。

本项目没有复制整个低代码平台代码库，只把成熟的图编辑器能力作为依赖接入；表单设计 Schema、数字化库联动、模型四阶段、公式执行与发布校验仍属于本项目逻辑。
