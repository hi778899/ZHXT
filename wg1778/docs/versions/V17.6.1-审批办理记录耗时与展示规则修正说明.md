# V17.6.1 审批办理记录耗时与展示规则修正说明

## 一、修订范围

本次只调整审批模型普通用户界面的“审批办理记录”展示规则，并同步修订规则文件、回归测试和审批办理记录运行快照。审批路径、审批人、规定时限、提醒、应完成时间、超时判断及智选触发逻辑保持不变。

## 二、审批/审查要求展示

审批模型内部仍可计算并保存本环节审批/审查要求，用于模型运算与审计留痕。

普通用户查看“审批办理记录”时，不再显示“本环节审批/审查要求”。审批人计算依据、审批路径计算依据同样继续保持后台保存、前台隐藏。

## 三、规定时限与实际耗时

“规定时限”仍是当前审批节点内部计算数据，继续用于提醒、应完成时间和超时判断；其来源仍为模型时限数字化库。

但在“审批办理记录”中，不再展示规定时限，改为展示该环节真实办理耗时：

`耗时 = 办理时间 - 到达时间`

耗时直接使用真实到达时间和真实办理时间计算，不读取规定时限、不读取应完成时间，也不以固定值代替。

展示格式按实际差值自动组合为“天、小时、分、秒”。未形成办理时间、时间无效或办理时间早于到达时间时显示 `—`。

## 四、兼容性

历史审批办理记录已经保存 `arrivedAt` 和 `handledAt` 时，无需数据库迁移即可直接计算耗时。

新生成的审批办理记录同时保存 `elapsedMilliseconds` 作为机器可核验差值，但前端展示仍以到达时间和办理时间直接计算，避免历史数据兼容问题。

## 五、当前有效规则

本次将以下规则的当前有效版本升级为 V17.6.1：

- `.ai/rules/07_APPROVAL_SMART_SELECT_RULES.md`
- `.ai/rules/17_APPROVAL_MODEL_INTERNAL_LOGIC_RULES.md`
- `.ai/rules/18_DASHBOARD_RULES.md`

核心约束为：

1. 审批办理记录不显示本环节审批/审查要求；
2. 审批办理记录不显示规定时限；
3. 审批办理记录显示真实耗时；
4. 耗时严格等于办理时间减去到达时间；
5. 规定时限仍在后台用于提醒、应完成时间、超时判断和审计留痕。
