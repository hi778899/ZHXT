# V17.1.1 数字化标识双层表头修正说明

本版本在 V17.1 数字化库 DataEase 风格重构版基础上进行显示规则修正。

## 修正内容

1. 数字化库“数据记录”表格不再隐藏数字化标识。
2. 每一个业务字段表头统一采用双层结构：
   - 第一行：中文字段名称；
   - 第二行：对应 16 位数字化标识。
3. 必填标记仍跟随中文字段名称显示。
4. 数字化标识同时继续保留在“字段设计”“模型关联”“记录详情”中。
5. 不修改四阶段模型建设、标准库数据源、审批模型、智选模型及数据库核心结构。

示例：

```text
申请人
5013001005001101
```

这样既保证业务人员能直接阅读字段含义，也保证数字化标识作为系统数字化结构的一部分始终可见、可核验。
