# V11 用户发起模型进入“我的已办”说明

## 修复问题
V10 的“我的已办”只查询本人办理过的 `todos`，因此用户本人从“可发起模型”提交并已经归档的模型运行记录不会出现。

## V11 处理原则
“我的已办”统一展示两类本人已完成工作：

1. **本人办理记录**：本人作为待办负责人已经处理完成/退回的事项；
2. **本人发起记录**：本人通过“可发起模型”人工发起的模型运行记录。

跨模型自动触发的审批模型、智选模型、后续模型不作为“本人发起”重复展示。系统通过 `model_runs.trigger_mode` 区分 `manual / hard_link / smart / schedule / quantity`。

## 请休假模型示例
张珊提交请休假申请后：

- 请休假模型自身完成业务计算并归档；
- “我的已办”立即出现“请休假申请”；
- 请休假模型归档后仍按模型关系触发独立审批模型；
- 部门经理、考勤主管的审批待办只进入各自账号的“我的待办”；
- 审批模型等由系统触发的后续模型不会冒充张珊“本人发起”的记录。

## 界面调整
发起成功后，没有本人待办需要处理时，页面进入“我的已办”，并自动重新读取服务器工作记录。已办详情可查看本次模型的业务字段，不展示模型文件名、数字化标识等技术字段。
