# V8 请休假两步独立审批

## 模型边界

- 请休假模型：仅负责发起人填写、业务计算、业务归档。
- 请休假模型归档完成后，通过第 4 阶段配置的硬性链接触发独立审批模型。
- 审批模型：仍由模型建设四个阶段建立，不作为请休假模型内部节点。

## 请休假审批模型默认两步

1. 行政审批：负责人为“考勤主管”，按全局角色匹配。
2. 业务审批：负责人为申请人所属部门的“部门经理”，按部门 + 角色动态匹配。

只有行政审批“同意”后才生成业务审批待办；任一步“不同意”或“退回修改”即结束审批模型并归档审批结论。

## 管理后台

用户管理中新增角色设置：普通用户、部门经理、考勤主管、系统管理员。上线前至少需要：

- 为一个有效用户设置“考勤主管”；
- 为每个会发起请休假的部门至少设置一名同部门“部门经理”。

如果审批模型找不到对应角色，不再回退给发起人，而是明确提示缺少角色配置，避免错误审批。

审批待办标题支持 `{sourceModelName}` 占位符，例如请休假模型触发后显示“请休假模型审批 · 行政审批”。
