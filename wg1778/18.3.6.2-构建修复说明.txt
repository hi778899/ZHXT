智慧企业治理系统 V17.6 / 18.3.6.2 构建修复说明

修复范围：仅修复 server/src/model-templates.ts 的 TypeScript 编译错误，不调整业务逻辑。

1. 修复智选模型 configuration.digitalStructureVersion 编译错误
原因为 baseConfig() 返回对象的推断类型中没有 digitalStructureVersion 字段，后续直接赋值触发 TS2339。
处理方式：改为对象展开时一次性加入 digitalStructureVersion:"0622"，与审批模型配置写法保持一致。

2. 补充 StandardLibrarySpec 类型定义
原源码在基础数字化库模板中引用 StandardLibrarySpec，但没有定义，触发 TS2304。
补充字段：code、identity、libraryId、libraryName、fields、outputKeys。

服务器重新构建命令：
cd 项目目录
docker compose down
docker compose up -d --build
docker compose ps
docker compose logs --tail=120

如果只覆盖源码后重建，也可以直接执行：
docker compose up -d --build
