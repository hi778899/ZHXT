请设计一个“企业智能化数字工作驾驶舱”Web端高保真界面。

注意：这里的“驾驶舱”不是传统的数据可视化大屏，而是企业员工登录后的统一数字化工作门户和操作界面，重点是业务操作、任务处理、模型运行、信息查看和快捷入口。

【整体设计要求】

页面尺寸按桌面端设计，建议 1440×900 或 1920×1080，自适应布局。

整体风格：
- 企业级、科技感、专业、简洁
- 类似大型央企数字化管理平台
- 采用浅色背景
- 白色卡片
- 少量蓝色作为主色
- 页面整洁，不要过度使用渐变、霓虹、发光效果
- 不要设计成传统 BI 数据大屏
- 强调“工作门户”“操作驾驶舱”“模型操作入口”
- 使用统一圆角卡片和轻微阴影
- 模块层级清晰
- 信息密度适中

十一、交互逻辑

这是一个真正的可操作驾驶舱，因此所有核心模块都需要设计 hover 和 clickable 状态。

交互关系：

点击“新建”
→ 进入本人可发起模型列表

点击“待办”
→ 进入我的待办

点击某一待办
→ 进入该事项对应的业务处理页面

点击“已办”
→ 进入本人已办记录

点击“模型建设”
→ 进入本人模型建设阶段

点击“数据查询”
→ 查询本人权限范围内的数字化库历史数据

点击公共信息
→ 打开对应通知或信息详情

点击最近使用 / 最近查询 / 收藏要素
→ 进入对应内容
