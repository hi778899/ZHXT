# V17.4.1 审批中文字段与审批人路径计算说明

本版基于 V17.4 规则补充实现。

1. 审批模型新建和用户可见字段统一使用中文业务名称；历史英文键仅在运行引擎内部做兼容读取。
2. 新增数据库迁移 019，将既有“审批模型”的模型设计、测试数据和配置中的历史英文字段口径转换为中文字段口径。
3. 审批模型运行结果保存“审批人计算”“审批路径计算”“正式审批路径节点”，每个路径节点包含实际审批人、审批组织、审批层级/岗位、审批要求、规定时限和计算依据。
4. “正式审批路径”显示具体节点及审批人，不只显示抽象环节名称。
5. 我的已办、我的办结打开审批模型时，直接读取审批模型自身运行结果，并显示审批人计算、审批路径计算和逐环节办理记录。
