# V17.1.2.3 TypeScript 生产构建修复说明

## 修复问题
Docker 执行 `pnpm run build:all` 时，服务端 TypeScript 严格模式报错：

- `server/src/data-linkage.ts(...): TS7006 Parameter 'item' implicitly has an 'any' type`

## 修复方式
对 `design.calculations` 与 `design.expressions` 的过滤结果明确声明为：

```ts
Record<string, unknown>[]
```

并在 `filter` 中使用显式类型守卫，使后续 `find(item => ...)` 的 `item` 获得确定类型。
