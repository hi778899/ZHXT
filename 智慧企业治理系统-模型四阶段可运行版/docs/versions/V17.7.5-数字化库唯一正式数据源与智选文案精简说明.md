# V17.7.5 数字化库唯一正式数据源与智选文案精简

对应代码包：18.3.6.9。

## 本次调整

1. 删除智选详情“这仍是一条完整、有效的智选模型运行记录”等解释性结论文案；无关联模型时只显示实际值“无”。
2. 明确模型业务数据的唯一正式来源为对应数字化库；`model_runs` 只负责运行主键、文件名、状态、时间和关联追溯。
3. 智选详情按 `smart_run_id` 定位运行后：
   - 原业务内容读取原业务模型数字化库；
   - 审批结果读取审批模型数字化库；
   - 智选判断、关联模型集合、启动明细读取智选模型数字化库。
4. 智选详情接口新增来源审批模型数字化库记录，不再向前端使用 `model_runs.input_data/output_data` 作为正式业务字段。
5. 智选模型数字化库归档补充来源审批模型运行记录、来源审批模型文件名、统计分析模型文件名。
6. 当前审批节点“规定时限”直接采用模型时限数字化库匹配形成的节点正式值；审批人计算、运行快照和 output 仅作为运算留痕，不再反向补值。
7. 审批办理记录仍保持 `耗时 = 办理时间 - 到达时间`，不展示规定时限。

## 数据源原则

统一链路：

`run_id / 模型文件名 → 定位模型运行 → 定位对应数字化库 → 按数字化标识读取正式数据 → 页面展示/后续模型使用`

不新增数据库 migration，兼容现有数字化库及历史运行记录；历史记录缺少对应数字化库记录时，页面显示“— / 无 / 未形成”，不回退使用运行 JSON 伪造正式数据。
