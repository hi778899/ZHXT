# V9 请休假审批人员与账号说明

## 1. 请休假模型与审批模型边界

请休假模型只负责申请人填写、业务运算、业务结果形成和请休假模型归档。请休假模型归档完成后，通过硬性链接触发独立审批模型。

## 2. 审批模型默认两步顺序

1. 行政审批：由申请人所属部门的“部门经理”账号办理。
2. 业务审批：行政审批同意后，由全局“考勤主管”账号办理。
3. 任一步“不同意”或“退回修改”，审批模型终止，不再进入下一审批步骤。
4. 两步均同意后，审批模型形成最终审批结果并归档。

## 3. 默认账号

系统启动时会确保存在两个独立审批人员账号：

- 部门经理：默认账号 `deptmanager`，默认属于“设备管理部”，角色 `department_manager`。
- 考勤主管：默认账号 `attendance`，默认属于“综合管理部”，角色 `attendance_supervisor`。

首次通过 `start-production.sh` 启动时，两个账号会生成随机密码，并与管理员账号一起写入 `首次启动账号.txt`。可在 `.env` 中修改账号、姓名、部门和密码。

## 4. 审批人匹配规则

行政审批读取请休假申请中的 `department`，查找该部门下启用状态且角色为 `department_manager` 的账号。业务审批查找启用状态且角色为 `attendance_supervisor` 的账号。

若对应审批人员不存在，系统停止流转并明确提示管理员配置人员，不回退给申请人本人。
