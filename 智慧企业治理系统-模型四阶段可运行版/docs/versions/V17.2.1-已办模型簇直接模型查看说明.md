# V17.2.1 已办模型簇直接模型查看说明

本版在 V17.2 基础上只调整“我的已办”模型簇交互，不改变模型运行、数字化库硬性链接、审批模型、智选模型或数据库结构。

## 1. 已办根记录仍为业务模型

“我的已办”继续以人工发起的业务模型文件名作为根记录。业务模型正式入库后显示“申请阶段”，审批模型完成归档后显示“有效阶段”。

## 2. 展开后直接显示关联模型

业务模型行展开后不再展示“模型簇进度”或独立的“审批模型进度”界面，只显示该业务运行关联的模型记录：

- 审批模型：显示审批模型文件名、模型状态，并提供“查看审批模型”；
- 智选模型：显示智选模型文件名、模型状态，并提供“查看智选模型”。

尚未启动的模型只显示“未启动”，不伪造模型文件记录。

## 3. 点击模型就是查看模型本身

点击“审批模型”进入该次审批模型运行详情，可查看审批模型文件名、来源业务模型文件名、业务内容、审批结果和审批模型记录。

点击“智选模型”进入该次智选模型运行详情，可查看智选模型文件名、来源审批模型文件名、业务模型文件名、智选依据和智选结果。

业务模型本身的“查看业务模型”只展示该次业务模型运行内容及模型运行信息，不再进入模型簇进度页面。

## 4. 链路规则

本版继续沿用模型文件名传递和数字化库硬性链接规则：

`业务模型文件名 → 审批模型 → 审批模型文件名 → 智选模型`

页面只负责展示既有运行关系，不在前端生成审批/智选链路，不新增模型 ID 或实例 ID 作为业务口径。

## 5. 数据库与兼容性

- 不新增 migration；
- 不修改数据库表结构；
- 不修改现有运行引擎；
- 不修改数字化库正式入库规则；
- 不修改审批模型与智选模型触发方式；
- 已有 V17.2 历史运行记录继续兼容。
